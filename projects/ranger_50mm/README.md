# Ranger 50 mm

## Zadání

Figurka lidského rangera pro stolní hru AD&D, cílová výška 50 mm. Projekt je připraven pro Blender scény, tiskové exporty a prezentační náhledy. Model ani jeho dřívější verze zatím nebyly do repozitáře nahrány.

## Technické údaje

| Položka | Hodnota |
|---|---|
| Stav | Struktura připravena; soubory dosud nenahrány |
| Cílové rozměry | Výška figurky 50 mm; ostatní rozměry doplnit |
| Pracovní jednotky | Doplnit |
| Blender / CAD aplikace | Doplnit skutečně použitou verzi |
| Doplňky a závislosti | Doplnit, případně žádné |
| Orientace os a exportní měřítko | Doplnit pro jednotlivé formáty |
| Tiskárna, materiál a tolerance | Doplnit, pokud se týká tisku |
