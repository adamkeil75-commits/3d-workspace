# Společné skripty

Složka `blender/` je připravena pro opakovaně použitelné skripty pro Blender, například kontrolu rozměrů, dávkové exporty nebo renderování náhledů.

Zatím zde nejsou žádné spustitelné skripty.

Skripty použitelné pouze pro jeden projekt patří do `projects/<projekt>/scripts/`.

Ke každému přidanému nástroji uveď:
- účel a podporovanou verzi Blenderu nebo Pythonu;
- příklad spuštění;
- vstupy a výstupy;
- zda mění scénu nebo přepisuje soubory.
